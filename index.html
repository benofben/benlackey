Create a GitHub Personal Access Token

To avoid GitHub API rate limits, create a Personal Access Token (PAT) and paste it into the Sign-in prompt.

  1. Open GitHub settings: https://github.com/settings/tokens
  2. Choose Generate new token (classic) or create a fine-grained token.
  3. No scopes are required for reading public repositories; if you want private repo access, grant appropriate repo scopes.
  4. Copy the token and paste it into the app when prompted.

See GitHub docs for details: Creating a personal access token
